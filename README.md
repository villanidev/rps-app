# Running locally

Pre-requisites: Java 21 (LTS), Maven, Favorite IDE or terminal

```bash
# on your IDE
open as maven project and run it

# on your terminal
build the maven project, navigate to the target folder and run:
java -jar rps-app-1.0-SNAPSHOT-jar-with-dependencies.jar
```
